## Overview

An educational and productivity platform for students and developers. Stateful combines interactive algorithm visualizations, a cloud-synced code compiler, a RAG chatbot, and built-in study tools in one focused environment.

## Key Features

**Online Compiler & IDE** — Monaco Editor supporting C, C++, Java, and Python. Code snippets sync to the cloud via Firebase Firestore. Sandboxed execution powered by the Piston API.

**Algorithm Visualizer** — 60fps visualizations using Framer Motion for key sorting and graph algorithms. Makes complex CS concepts genuinely intuitive.

**Misa Amane (RAG Chatbot)** — Domain-restricted AI assistant using a local LLM via Ollama and a FAISS vector store. Includes a 5-layer hallucination prevention system to keep responses educational and reliable.

**Admin Dashboard** — Secure glassmorphic panel for user management and platform analytics.

**Study Tools** — Pomodoro timer, stopwatch, and live clock built in.
