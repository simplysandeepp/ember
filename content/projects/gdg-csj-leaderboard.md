## Overview

A real-time, dynamic leaderboard for the GDG On Campus Cloud Study Jam at Galgotias University. Tracks and visualizes participant progress through Google Cloud skill badges and labs.

## Features

- Live leaderboard with real-time rankings and badge completion counts
- Progress tracking across multiple defined Google Cloud learning paths
- Admin controls for updating and verifying participant data
- Event-optimized UI — clean, responsive, readable on large event screens
