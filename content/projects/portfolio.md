## Overview

A minimal, white-themed portfolio designed to let content speak for itself. No animations, no dark mode, no CMS — just markdown files and a static Next.js build deployed to Vercel.

## Design principles

- Typography first — Geist font, generous whitespace, consistent scale
- Content lives in `/content/*.md` files — adding a new project is just adding a file
- SEO baked in from day one: Open Graph, JSON-LD, sitemap.xml, robots.txt
- Static export — deploys anywhere, loads instantly

## Stack

Next.js 14 (App Router), TypeScript, Tailwind CSS, gray-matter, next-mdx-remote, Vercel
